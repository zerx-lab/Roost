整理本项目在 `.omp/memory/` 中的记忆。$ARGUMENTS

1. 读取 `MEMORY.md`、`topics/*.md`,以及最近两个月的 `journal/*.md`。
2. 逐条对照仓库现状核实(读代码、配置、`git log`):
   - 已失效的条目:删除;如果属于被推翻的决策,改写后移到「被否方案」并注明原因;
   - 同义重复的条目:合并为一条,保留最早的日期和全部依据;
   - journal 中仍有长期价值、但还没提炼的内容:按 `/remember` 的规则写入 MEMORY.md 或 topics。
3. 让 MEMORY.md 保持在 150 行以内。超出时,把细节下沉到 `topics/<slug>.md`,MEMORY.md 里只保留一句结论加索引。
4. journal 是历史记录,不要改写;只有当某个月份的条目已经全部提炼完毕时,才可以在该月文件顶部注明"已整理至 YYYY-MM-DD"。
5. 运行 `scripts/check.sh`,确认「项目记忆」检查通过,然后汇报:删除、合并、新增、下沉的条目各有几条,以及有疑问需要用户确认的条目。
